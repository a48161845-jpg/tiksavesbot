# TikSaves — Telegram-бот для скачивания видео, фото и музыки

Присылаешь ссылку — получаешь файл без водяных знаков. Площадки: TikTok (видео, слайдшоу, live-фото), YouTube, Instagram, VK, Pinterest, X, Rutube, Reddit. Работает в личке, в группах и в inline-режиме. Интерфейс на 6 языках: ru, en, uk, kk, uz, ky.

## Запуск

```bash
cp .env.example .env        # впиши BOT_TOKEN
pip install -r requirements.txt
python bot.py
```

В Docker: `docker build . && docker run --env-file .env <image>` (точка входа — `python bot.py`).

## Структура проекта

```
bot.py            точка входа: сессия, провайдеры, Dispatcher, polling
core/             ядро: config, storage (в т.ч. Premium), limiters, gates, stats, логи, helpers, donate,
                  nudge_texts / download_nudge (напоминания), broadcast (рассылки) …
downloaders/      скачивание: providers (tikwm + страница TikTok), photo_crop (обрезка фото), song_search (песня из поста), youtube_provider (yt-dlp),
                  platform_fallbacks (X, Reddit, Pinterest, Instagram), tiktok_live, cobalt_client,
                  media_fetch, photo_video, video_compress, video_meta
ui/               theme (единый стиль текстов), keyboards (экраны и кнопки), send_helpers
                  (отправка медиа), picker_state / quality_state / support_state (состояние диалогов)
i18n/             переводы: __init__ (tr, языки), screens (экраны нового оформления),
                  texts / extra / cis / gifts (остальные строки), error_explain (понятные ошибки)
handlers/         обработчики Telegram: main_handler (TikTok), youtube_handler, other_sources_handler,
                  picker/quality/video_choice callbacks, inline, commands, admin, donate, settings,
                  support, group_links (ссылки в группах)
legacy/           отключённый архив (рефералка, магазин подарков, старый TikTok-хендлер) — не подключён
tools/            diag_quality — ручная диагностика качества:  python -m tools.diag_quality <ссылка>
tests/            тесты без сети и без зависимостей
```

Правило слоёв: `core` ничего не знает про остальных; `downloaders` зависят от `core`; `ui` и `i18n` — от `core`; `handlers` собирают всё вместе.

## Оформление интерфейса

Тексты экранов всех языков лежат в одном месте — `ui/screens_text.py` (фразы `PHRASES[язык]` и функция `build(язык)`); русские константы в `ui/keyboards.py` и переводы в `i18n/screens.py` берутся из неё же, поэтому разметка у оригинала и перевода совпадает всегда. Чтобы поправить текст экрана — правь фразы в `PHRASES`. Экраны собираются функциями из `ui/theme.py`: заголовок `<b>🎵 Название</b>`, шаги с жирными цифрами, подсказки в `<blockquote>`, без разделителей из «━━━». Ключ перевода — сам русский текст; новые экраны переводятся в `i18n/screens.py` теми же функциями, а тест `tests/test_screens.py` проверяет, что разметка у перевода совпадает с оригиналом.

## Возможности и настройка (переменные окружения — см. `.env.example`)

- **Донат.** Telegram Stars, подарки, Donation Alerts и вкладка «🇷🇺 Донат рублями (для РФ)» — Ozon Банк (СБП): `OZON_DONATE_URL`.
- **Группы.** Бот сам обрабатывает каждую ссылку, присланную в чат (текст, подпись к медиа, спрятанная ссылка, до 3 ссылок в сообщении), и молчит на обычные сообщения. Чтобы видеть все сообщения, бот должен быть администратором группы или с отключённым Privacy Mode (`/setprivacy` в @BotFather). `GROUP_AUTO_LINKS=0` — выключить.
- **TikTok live-фото.** Кадры с live-клипом помечены 🎞 в выборе фото и в подписи к альбому. Если tikwm не разобрал ссылку, данные читаются прямо со страницы TikTok (провайдер `tiktok-page`), короткие ссылки раскрываются ещё и через oEmbed.
- **Формат фото.** В выборе кадров две строки кнопок: «📐 Оригинал», 1:1, 4:3, 3:4, 16:9, 9:16. Выбранный формат применяется при «Скачать всё» и «Продолжить»: фото обрезаются по центру (`downloaders/photo_crop.py`, нужен Pillow), live-клипы идут без обрезки.
- **Inline для фото.** `@tiksavesbot <ссылка на TikTok-пост с фото>` показывает список кадров (до `INLINE_PHOTO_LIMIT`, по умолчанию 10) — каждый отправляется отдельным сообщением. После ссылки можно дописать формат: `1:1`, `4:3`, `3:4`, `16:9`, `9:16` — кадры обрежутся по центру. У каждого формата свой кэш `file_id`, повторный запрос отвечает мгновенно. Live-клипы в inline не поддерживаются.
- **💎 Premium (за Telegram Stars).** `/donate` → «💎 Premium»: тарифы 30 / 90 / 365 дней (цены — `PREMIUM_STARS_30/90/365`, по умолчанию 150 / 400 / 1200 ⭐). Даёт лимиты ×`PREMIUM_LIMIT_MULT` (3), отключает напоминания о донате, ставит значок 💎 в `/me`. Срок продлевается: новый период добавляется к оставшемуся. Админ может выдать/снять вручную: `/premium ID дней`, `/premium ID off`. `/paysupport` — обязательная для платежей команда (куда писать, если оплата не прошла). Код: `handlers/premium.py`, `core/storage.py` (`grant_premium`…), `core/limiters.py`.
- **Напоминания о донате.** После каждого `NUDGE_EVERY`-го скачивания (по умолчанию 2) пользователь получает «кричащее» сообщение с кнопками (Stars / любой банк по СБП / Donation Alerts / Premium): 70% донат (6 вариантов), 20% промо Premium, 10% про `/support`. У Premium-пользователей напоминаний нет. Тексты и переводы на 6 языков — `core/nudge_texts.py`, логика — `core/download_nudge.py`.
- **Кнопки прямо на фото и видео.** Под видео — «🎵 Музыка / 📝 Описание» и «💛 Донат · 💎 Premium · 🔗 Поделиться». Под фото то же самое висит прямо на последнем кадре; к альбому Telegram кнопки прикрепить не даёт, поэтому последний кадр уходит отдельным сообщением с кнопками и подписью, а остальные — альбомом перед ним.
- **Донат рублями** — «с любого банка по СБП» (ссылка `OZON_DONATE_URL`, название банка пользователям не показывается).
- **Админ-панель** (`/admin`): сводка за сегодня и состояние базы; кнопки «📣 Рассылки» (готовые шаблоны: «🔥 Донат», «💎 Premium», «📌 /support» — с предпросмотром, кнопками под сообщением, прогрессом и итогом «доставлено / заблокировали бота / ошибки / время»), «💎 Premium», «🔧 Тех. режим» (переключатель), «💥 Ошибки», «🚫 Бан-лист» и др. Свой текст: `/broadcast текст`.
- **Поддержка.** Под экраном `/support` есть «❌ Отмена» (и команда `/cancel`) — если открыли случайно. Кнопка «🆘 Поддержка» в меню доната теперь тоже по-настоящему открывает обращение (раньше только показывала текст).
- **Админ пишет пользователю.** `/msg ID текст` или `/msg @username текст`; либо `/admin` → «✉️ Написать пользователю» (можно отправить и фото/файл/голосовое). Пользователь получает «📩 Сообщение от администрации» с кнопкой «💬 Ответить» — она открывает поддержку, ответ придёт админу.
- **Режим Bot API.** `/botapi` (админ) показывает, работает ли локальный сервер (лимит файла 2 ГБ) или облачный (≈50 МБ) и **почему**: какие переменные не заданы, найден ли `.env` и бинарник. Та же причина пишется в сообщение «Бот запущен» в канале логов. Чтобы лимит был 2 ГБ, нужны `API_ID` и `API_HASH` (my.telegram.org) в окружении или в `.env` рядом с `bot.py`.
- **Статистика «по источникам»** считает только платформы (TikTok, YouTube, Instagram, …). Внутренние названия способов скачивания (запасной yt-dlp, зеркала и т.п.) раньше попадали туда как отдельные «источники» — теперь вливаются в свою платформу, а старые данные при запуске объединяются автоматически.
- **Песня из TikTok-видео.** Из данных поста берём название и автора трека (tikwm `music_info`, страница TikTok, yt-dlp `track/artist`). Под видео появляется кнопка «🔎 Найти песню»: карточка с названием, ссылками на поиск в YouTube Music / Spotify / Apple Music / Яндекс Музыке и кнопкой «⬇️ Скачать аудио». Звук приходит файлом с правильными тегами (название и исполнитель) и теми же кнопками поиска; строка «🎵 Название — Автор» добавляется и в подпись видео и фото. Если это «оригинальный звук» автора (в стримингах его обычно нет), бот так и скажет и предложит поиск на YouTube по автору. Код: `downloaders/song_search.py`.
- **Instagram.** yt-dlp → страница встраивания → зеркала (`INSTAGRAM_MIRRORS`). Закрытые и ограниченные посты скачать нельзя. При ошибке 429 или блоке IP помогает `YTDLP_PROXY`.

## Тесты

```bash
python tests/check_imports.py              # статическая проверка всех импортов проекта
python tests/check_code.py                 # несуществующие методы store/lim, забытые await, плейсхолдеры tr(), дубли хендлеров
cd tests && python -m unittest discover    # парсеры, переводы, группы, клавиатуры
```

Тесты используют заглушки aiogram/aiohttp (`tests/stubs.py`), поэтому запускаются без установки зависимостей и без сети. Реальную работу с TikTok и Instagram они не проверяют — только разбор данных.
